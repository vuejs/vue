# Vue.js 中文文档

渐进式 JavaScript 框架。

## ✨ 特性

- 🧩 组件系统
- 📦 响应式数据绑定
- 🔄 指令系统
- 📱 Weex 支持

## 🚀 快速开始

```bash
npm create vue@latest
cd my-vue-app
npm install
npm run dev
```

## 📖 示例

```vue
<script setup>
import { ref } from 'vue'
const msg = ref('你好，Vue!')
</script>

<template>
  <h1>{{ msg }}</h1>
</template>
```
